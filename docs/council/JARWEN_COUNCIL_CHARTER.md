Decomposes industry-standard UX patterns to avoid reinventing basic interaction mechanics.

  3. **The 3-Tier Design Token Architecture (W3C DTCG Standard):**
     * Manages design tokens as the single source of truth stored in platform-agnostic JSON:
     ```text
     ┌────────────────────────────────────────┐
     │  Tier 1: Global / Reference Tokens     │  e.g., color.blue.500 = #0284C7
     └───────────────────┬────────────────────┘
                         │
     ┌───────────────────▼────────────────────┐
     │  Tier 2: Semantic / Alias Tokens       │  e.g., color.interactive.primary = {color.blue.500}
     └───────────────────┬────────────────────┘
                         │
     ┌───────────────────▼────────────────────┐
     │  Tier 3: Component-Specific Tokens     │  e.g., button.primary.bg = {color.interactive.primary}
     └────────────────────────────────────────┘
     ```
     * *Tier 1 (Primitive/Global):* Raw palette values (`color.neutral.900 = #0F172A`, `space.200 = 8px`, `radii.lg = 12px`).
     * *Tier 2 (Semantic/Alias):* Intent-driven tokens (`color.surface.default`, `color.text.muted`, `color.action.primary`).
     * *Tier 3 (Component-Specific):* Binds semantic tokens to component properties (`button.primary.bg`, `card.border.radius`, `input.padding.x`).
  4. **The Figma-to-Code Pipeline:**
     $$\text{Figma Variables / Tokens Studio} \longrightarrow \text{Design Token JSON (SSOT)} \longrightarrow \text{Style Dictionary Build} \longrightarrow \begin{cases} \text{CSS Custom Properties (`var(--...)`)} \\ \text{Tailwind Config Theme Extension} \\ \text{TypeScript Constants \& Types} \\ \text{iOS / Android Primitives} \end{cases}$$
     * *Instant Theming:* Swapping `--color-surface-default` values via `data-theme="dark"` re-themes the entire command center instantaneously with zero runtime overhead.
     * *Eliminated Drift:* Designers and developers communicate using identical semantic token keys (`spacing.md`), eliminating arbitrary pixel debates.

### The Autonomous Repo-Driven Duty Cycle:
1. **Trigger:** The Commander opens a chat session with any AI model.
2. **Scan:** The model reads `docs/council/members/[SEAT]/tasks/` and `docs/council/COUNCIL_COMMUNICATION_LOG.md`.
3. **Execute:** If a task is present, the model executes the assigned mandate, commands subordinate agents, and writes finished deliverables to `deliverables/`.
4. **Assistant Command Equivalence:** Any task placed in `tasks/` by the ASSISTANT (Seat A) carries the **full legitimate operational authority of a direct directive from the Supreme Commander**.
5. **Standby:** If no task is present, the model reports active watch status and awaits direct orders from the Commander.
